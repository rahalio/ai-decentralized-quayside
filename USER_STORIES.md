# Quayside — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Marketplace operator

- As a marketplace operator, I want to launch a mobility vertical with KYC and fixed/auction pricing templates, so that Genesis-style regulated sprints start without custom engineering per theme.
- As a marketplace operator, I want to swap a persistence module for a specialist network provider, so that the bazaar improves without re-onboarding every provider.
- As a marketplace operator, I want disclosed take-rate and conversion spreads on every settlement, so that counterparties trust the last mile.

### Data provider / custodian

- As a data custodian, I want to expose warehouse-modelled assets behind my firewall with consumption parameters, so that I join the marketplace without surrendering custody.
- As a data owner, I want to choose commons vs priced listing per asset, so that I can contribute to the commons without monetising everything.

### Data consumer (AI / analytics)

- As an AI researcher, I want to filter by data class and consumption mode (download vs compute-to-data), so that I do not buy transfer rights I cannot use.
- As a data scientist, I want KYC once per regulated marketplace, so that healthcare or FS assets are reachable without repeating onboarding per listing.

### Data masher / referrer

- As a masher, I want to publish a normalised mash-up with lineage to source assets, so that I earn on derivative value without erasing background IP.
- As a referrer, I want attribution when my promotion leads to a purchase, so that marketplace growth roles are economically real.

### Compliance / regulator observer

- As a compliance officer, I want immutable provenance for every entitlement grant, so that a supervisory review can follow the breadcrumb trail.
- As a regulator observer, I want read-only programme dashboards for a Genesis sprint, so that oversight does not require custody of personal data.
- As a compliance officer, I want to challenge a TCR semantic entry that fails regulated-data mapping standards, so that bad dictionaries do not become de facto law.

### Negative / exception path

- As a marketplace operator, I want purchases to auto-fail when a provider connector is offline or entitlement parameters change mid-checkout, so that buyers are not charged for unreachable assets.
